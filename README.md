# Nhận diện cấu trúc giải phẫu và công cụ

So sánh phân đoạn trên 3 bộ dữ liệu: CT bụng (AMOS, 40 ca), siêu âm tim (CAMUS), nội soi (CholecSeg8k).
Chạy toàn bộ trên Google Colab bằng `colab_run.ipynb` (GPU T4 trở lên).

1. Upload thư mục này lên `MyDrive/anatomy_project` (phải có `src/`).
2. Mở `colab_run.ipynb`, chạy lần lượt Cell 1 → 9.
3. Cell 5 cần Kaggle API token (nhập vào ô ẩn, không lưu trong notebook).

Dữ liệu, cache và kết quả không nằm trong repo. Giấy phép CAMUS và CholecSeg8k là CC BY-NC-SA 4.0 (phi thương mại).
